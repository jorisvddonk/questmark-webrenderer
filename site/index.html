Questmark webrenderer

A simple inline parser, interpreter and renderer for Questmark documents — write Questmark and play it directly in your browser.

Live demos

  • Space Alien
    A small conversation tree demonstrating states, options, context and preconditions.
  • Foreign functions
    Extending a Questmark document with custom JavaScript functions via extraForeignFunctions.
  • Pre-run hook
    Modifying (or preventing) the VM before it starts, using the preRun global.

Usage

Save your Questmark document as an .html file and add these two scripts at the bottom:

<script src="https://unpkg.com/questmark-webrenderer/dist/webRender-basic.js"></script>
<script src="https://unpkg.com/questmark-webrenderer/dist/main.js" type="module"></script>

Then open the file in your browser. See the README for the full details and customization options.
